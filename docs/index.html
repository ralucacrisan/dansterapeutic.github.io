Sunt Raluca Crișan si va invit la dans terapeutic. Cred că dansul terapeutic este orice formă de dans sau mișcare folosită în scop de relaxare, autocunoaștere, echilibru emoționak. Este diferită de terapia prin dans, se adresează în primul rând persoanelor care doresc să se bucure mai mult de viața de zi cu zi, fără a fi diagnosticate cu o problemă psihologică sau psihiatrică
