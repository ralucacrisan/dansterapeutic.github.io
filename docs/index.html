Dans terapeutic cu Raluca Crisan.

… vă invit să practicăm dans terapeutic ca orice formă de dans sau mișcare folosită în scop de relaxare, autocunoaștere, echilibru emoțional. Este diferit de terapia prin dans, se adresează în primul rând persoanelor care doresc să se bucure mai mult de viața de zi cu zi, fără a fi fost diagnosticate cu o afecțiune psihologică sau psihiatrică. Scopul nostru este prevenția acestor afecțiuni prin dezvoltarea și cultivarea armoniei personale.
